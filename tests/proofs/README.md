# Public development-proof evidence

`evidence/` is generated by `just prove`. It publishes only the material needed
to reproduce verification of the two research-only development proofs:

- verification keys;
- proofs;
- original public signals;
- one-limb-mutated public signals; and
- a SHA-256-bound provenance report.

Witnesses, proving keys and Powers of Tau artifacts remain excluded. The local
single-machine ceremony uses deliberately known entropy and provides no
production trust. A passing proof demonstrates satisfaction of the recorded
arithmetic circuit only.
